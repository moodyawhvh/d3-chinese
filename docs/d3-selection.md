# d3-selection

选择集让文档对象模型(DOM)的强大数据驱动变换成为可能:设置[属性](./d3-selection/modifying.md#selection_attr)、[样式](./d3-selection/modifying.md#selection_style)、[property](./d3-selection/modifying.md#selection_property)、[HTML](./d3-selection/modifying.md#selection_html) 或[文本](./d3-selection/modifying.md#selection_text)内容等等。借助[数据联接](./d3-selection/joining.md)的 [enter](./d3-selection/joining.md#selection_enter) 和 [exit](./d3-selection/joining.md#selection_enter) 选择集,你还可以[添加](./d3-selection/modifying.md#selection_append)或[移除](./d3-selection/modifying.md#selection_remove)元素,使其与数据保持对应。

参阅以下章节:

* [选取元素](./d3-selection/selecting.md) - 查询 DOM 元素。
* [修改元素](./d3-selection/modifying.md) - 修改被选中元素的属性。
* [联接数据](./d3-selection/joining.md) - 把数据联接到选定元素上进行可视化。
* [处理事件](./d3-selection/events.md) - 声明用于交互的事件监听器。
* [控制流](./d3-selection/control-flow.md) - 遍历被选中的元素。
* [局部变量](./d3-selection/locals.md) - 把状态附加到元素上。
* [命名空间](./d3-selection/namespaces.md) - 处理 XML 命名空间。

更多内容请见 [Observable 上的 d3-selection 合集](https://observablehq.com/collection/@d3/d3-selection)。
