# d3-array

数组操作、排序、查找、汇总统计等。

参阅以下章节:

* [数值累加](./d3-array/add.md) - 以完整精度对浮点数求和。

* [数据二分](./d3-array/bisect.md) - 在有序数组中快速查找值。
* [数据模糊](./d3-array/blur.md) - 在一维或二维上对定量值做模糊处理。

* [值驻留](./d3-array/intern.md) - 创建支持日期等非原始值作为键的 Map 和 Set。
* [集合运算](./d3-array/sets.md) - 集合上的逻辑运算。
* [数据排序](./d3-array/sort.md) - 对值数组排序和重排。
* [数据汇总](./d3-array/summarize.md) - 计算汇总统计量。
* [刻度值](./d3-array/ticks.md) - 从连续区间生成有代表性的值。
* [数据变换](./d3-array/transform.md) - 派生新数组。
