# d3-scale-chromatic

该模块提供连续型、发散型和分类型配色方案,专为配合 [d3-scale](./d3-scale.md) 的 [d3.scaleOrdinal](./d3-scale/ordinal.md) 和 [d3.scaleSequential](./d3-scale/sequential.md) 而设计。其中大部分方案源自 Cynthia A. Brewer 的 [ColorBrewer](http://colorbrewer2.org)。由于 ColorBrewer 只发布离散配色方案,连续型和发散型比例尺的颜色是使用[均匀 B 样条](https://observablehq.com/@d3/colorbrewer-splines)插值得到的。

参阅以下章节:

* [分类配色方案](./d3-scale-chromatic/categorical.md)
* [循环配色方案](./d3-scale-chromatic/cyclical.md)
* [发散配色方案](./d3-scale-chromatic/diverging.md)
* [连续配色方案](./d3-scale-chromatic/sequential.md)
